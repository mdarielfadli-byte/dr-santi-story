# Paid Media readiness — Dr Santi's Story

## What is ready

- Production website and campaign/event landing-page pattern
- Contact inquiry form with consent and service-interest field
- Google Tag Manager loader in the website source
- Google Search Console baseline recorded in `SEO_BASELINE.md`

## Required before campaign creation

1. One primary objective: qualified inquiries, event registrations, resource leads, or website reach.
2. Budget, start/end date, target locations, target audience, and approved platform.
3. One named follow-up owner and response-time agreement for inquiries.
4. Approved creative set: at least three static/video variants, copy, CTA, and destination URL.
5. Measurement decision: the primary conversion and which events must be reported weekly.

## Recommended first test

Run one conversion-oriented campaign to a dedicated landing page or the inquiry form, with three creative variants and one clear CTA. Measure landing-page views, form starts, completed inquiries, cost per inquiry, and response time. Do not use organic Instagram follower growth as the primary KPI; it is an assisted outcome, not a reliable paid-media conversion.

## Weekly report

Report spend, reach, impressions, clicks, CTR, landing-page views, inquiries, cost per inquiry, qualified inquiries, and the creative/audience decision for the following week.
